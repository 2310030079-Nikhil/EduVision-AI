🏗️ Technical & Deployment Architecture

Why Streamlit + Vercel? Streamlit applications require a stateful persistent WebSocket server for bidirectional state reactivity, whereas Vercel provides high-speed Serverless Edge distribution. EduVision AI unites both:

User Browser ──────────► Vercel Edge Portal (Static & Serverless API Routes) │ └─────────────────► Streamlit Runtime (FAISS Vector Store, Groq LPU API, Session State) │ ├─► Groq LPU (llama-3.3-70b-versatile, llama-3.2-11b-vision) ├─► FAISS / SentenceTransformers (Document Chunk Retrieval) └─► Safe AST Calculator & Web Search Tools
